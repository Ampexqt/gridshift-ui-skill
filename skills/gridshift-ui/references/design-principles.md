# Design Principles

## 1. Product first, atmosphere second

The interface should explain the state of a decentralized network and help users operate it. Cyberpunk styling is the visual language—not the product itself.

## 2. Dense, not cluttered

Use compact modules and aligned data, but preserve clear grouping, sufficient spacing, readable text, and a strong focal point. Density means useful information per screen, not maximum decoration.

## 3. Hierarchy before effects

A suggested attention order:

1. Current node state and primary action.
2. Personal contribution and points.
3. Network health and recent activity.
4. Leaderboard and historical trends.
5. Terminal logs and secondary information.

Adapt this order to the actual product workflow.

## 4. Monochrome with intentional contrast

Use white for primary values, gray for metadata, and subtle borders for structure. Reserve glow for selected focus elements or important status moments. Do not make every panel equally bright.

## 5. Functional realism

A system log should describe meaningful application events. A live indicator should represent a real connection or a clearly identified simulation. A graph should show sourced or explicitly mocked data. Do not invent technical credibility.

## 6. Originality

Use the public product as inspiration for mood and information density. Do not reproduce proprietary screenshots, logos, exact copy, or unique layouts as a one-to-one clone. Establish an original component system.

## 7. Anti-patterns to avoid

- Generic dashboard grids made from identical rounded cards.
- Oversized hero headings that waste space in an operational console.
- Neon glow on every label, border, and number.
- Continuous scrambling text that is hard to read.
- Randomly changing metrics presented as live data.
- Fake terminal output with no connection to application state.
- Tiny gray text with inadequate contrast.
- Decorative charts with no labels, units, or meaningful scale.
- Hover-only controls that cannot be reached by keyboard.
- A desktop layout merely squeezed onto mobile.
- Unnecessary 3D effects, blur, or animation that harms performance.
